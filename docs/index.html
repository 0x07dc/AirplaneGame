CROSS-DISTRO PACKAGING

Install on Linux

Install directly from the Arch User Repository using yay or paru:

yay -S airplane-game
yay -S airplane-game-git # Cutting-edge main branch

Universal sandboxed package for Fedora, Ubuntu, Debian, and openSUSE:

flatpak install flathub io.github._0x07dc.AirplaneGame
flatpak run io.github._0x07dc.AirplaneGame

Compile with full LLVM LTO and SIMD optimizations via Zig 0.16.0:

zig build -Doptimize=ReleaseFast
./zig-out/bin/airplane_game --benchmark
